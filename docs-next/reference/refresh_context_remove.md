## refresh context remove

Remove a saved context

### Synopsis

Remove a saved context. When it is the active context, no context is active
afterwards.

```
refresh context remove <name> [flags]
```

### Examples

```
  refresh context remove prod
```

### Options

```
  -h, --help   help for remove
```
